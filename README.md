# 🎯 Research Philosophy

Forecasting is not only about obtaining the smallest error.

I am interested in understanding:

* Which models perform best?
* Does additional information improve forecasts?
* Does performance change across horizons?
* How stable are models through time?
* How does uncertainty affect predictions?
* Do improvements remain statistically meaningful?

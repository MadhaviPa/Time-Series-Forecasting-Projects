# ⏳ Time-Series Forecasting Portfolio | Madhavi Panchangum

> **Turning historical data into forecasts and actionable insights using statistics, econometrics, and machine learning.**


This repository contains forecasting projects where I work with **real-world economic and public-health data**, build predictive models, evaluate their out-of-sample performance, and translate the results into meaningful insights.

My work combines **time-series analysis, econometrics, machine learning, and forecast evaluation**.

## 🚀 Projects

### 1.  🦠 COVID-19 Case Forecasting

Forecasting COVID-19 cases in Germany and comparing traditional time-series models with machine-learning approaches.

**Models:**
`AR` • `ARX` • `SARX` • `Regression Tree` • `Random Forest`

**What this project demonstrates:**
Time-series modeling • Feature engineering • Machine learning • Rolling/expanding validation • Forecast comparison

### 2. 🇺🇸 U.S. Industrial Production Forecasting

Forecasting U.S. industrial production using a large set of macroeconomic and financial indicators.

**Methods:**
`Elastic Net` • `Quantile Elastic Net` • `PCA`

**Forecast horizons:**
`1` • `3` • `6` • `12` • `24 months`

**What this project demonstrates:**
Macroeconomic forecasting • High-dimensional data • Regularization • Mixed-frequency data • Quantile forecasting • Multi-horizon evaluation
